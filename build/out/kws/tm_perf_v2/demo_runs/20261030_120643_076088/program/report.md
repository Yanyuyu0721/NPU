# TinyMaix KWS A7 同口径测试结果

状态：通过。
时间：2026-10-30T12:07:03.860092+08:00。

平台：XC7A100T，CPU/NPU 同为50 MHz。计时仅包围 tm_run_cpu/tm_run；模型加载、输入预处理、清缓存和UART不在时间内。每次NPU调用仍准备权重；普通卷积使用硬件窗口，深度卷积以寄存器保留重叠窗口并整层批提交。8层卷积的116个通道由精确PPU执行量化，4个通道保留软件量化。硬件输出使用32位批量布局转换。没有持久权重驻留。

CPU稳态剔除第一次调用，CPU／未命中／命中各取后续5次的中位数；NPU首次调用只测1次。

13层CPU/NPU输出哈希全部一致；所有计时调用的最终三分类浮点位模式一致。每次NPU推理有11次真实提交。
输出概率：[0.98828125, 0.0078125, 0.00390625]。

数值口径：TM_NPU_CPU_COMPAT=1，NPU执行INT32乘加及偏置，混合精确PPU/软件量化与激活保持TinyMaix CPU的逐位结果。量化系数随不可变模型缓存：首次构建计时，后续复用。GAP和3个FC的量化使用从模型参数生成的精确函数表；不缓存输入、激活或分类结果。

模型：既有三分类TinyMaix KWS模型，9448字节、13层；与之前自定义EdgeModel网络不同。输入是同一录音FBank的布局转置，按模型64×40×1声明供给。尚不能证明此模型就是论文9.23倍实验所用的精确版本。
