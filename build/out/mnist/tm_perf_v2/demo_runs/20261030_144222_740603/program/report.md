数值口径：TM_NPU_CPU_COMPAT=1，NPU执行INT32乘加及偏置，3层卷积的量化与ReLU在PPU执行，采用精确倒数乘法与校正保留TinyMaix Q8的逐位结果；FC量化仍为软件。量化系数随不可变模型缓存：首次构建计时，后续复用。普通卷积已启用硬件PPU；FC、GAP和Softmax仍在CPU执行；量化与指数函数使用从模型参数生成的精确函数表，不缓存输入预测结果。新增完整域输出反量化表及保守Softmax量化区间快路径，未改变数值结果。

模型：既有TinyMaix MNIST CNN，2408字节、6层（3个卷积、GAP、全连接、Softmax），28×28×1、10类。与旧EdgeModel MLP不同；使用同一原始MNIST样本，不转置。尚不能证明此模型就是论文11.3倍实验所用的精确版本。
